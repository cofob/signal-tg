# Итерации до полного клиента

Цель: стабильный, быстрый, приватный и безопасный клиент Signal с функциями настольного и мобильного Signal (кроме невозможного на платформе: FCM, Google Pay), регистрацией по номеру, без кода Telegram API и Telegram-функций, с Tauri-версией для macOS, Windows и Linux и собственной темой в стиле Signal.

Каждая итерация: запуск субагентов → ожидание → проверка (tsc, ESLint, CSS, браузер, живой тестовый аккаунт) → исправления → план следующей → запуск. После каждого слияния изменения пушатся в рабочую ветку и `master`.

## 1. Основа (идёт)
- Вычищение сетевых обращений к Telegram, CSP только на свой origin и туннель.
- Перенос истории при привязке (link-and-sync).
- HTTP/2 для storage, групп и CDN; исправление приёма и записи больших объёмов в TLS-клиенте WASM.
- Этап 1: удаление функций Telegram (платные функции, проверки Premium, перевод, AI, викторины, теги, chatlists, custom emoji, Instant View, карты, облачный пароль, модалки, каналы, форумы, боты, Mini Apps).
- Интерфейс: эмодзи в реакциях, плашки удалённых сообщений, галочки доставки и прочтения, цвета аватаров, свой профиль.

## 2. Без Telegram и десктоп
- Удаление GramJS и Telegram API (этап 3): воркер, типы методов и действия только на Signal; строки локализации в сборке (английский и русский).
- Tauri: транспорт через команды и IPC-каналы на библиотеке туннеля, трей и системные уведомления, новое имя и иконки, обновления с наших релизов, сборки для macOS, Windows и Linux в CI.
- Уведомления в браузере при открытой вкладке.

## 3. Группы и синхронизация
- Управление группами v2: создание, название, описание, аватар, участники, админы, права, ссылки-приглашения с одобрением, заявки, баны, выход и завершение группы.
- Запись в storage service: архив, закрепы, mute, «непрочитанное», контакты, блокировки, настройки, папки.
- Синхронизация `deleteForMe`, запросы на переписку (принять, удалить, заблокировать, спам), блокировка.

## 4. Регистрация и основное устройство
- Регистрация по номеру: verification session, captcha, SMS и голосовой код, атрибуты аккаунта, ключи, профиль.
- PIN и SVR2/SVR3 (attestation: патч `attest` для WASM), registration lock, смена номера.
- Поиск по номеру через CDSI (attestation).
- Привязка других устройств к основному, управление связанными устройствами.

## 5. Медиа и контент
- Истории: просмотр, отправка медиа и текста, My Story, списки рассылки, групповые истории, ответы, реакции, просмотры.
- Стикерпаки: установка, отправка, синхронизация; превью ссылок через contentproxy; отправка контактов; интерфейс опросов и закрепов; альбомы из нескольких вложений.

## 6. Профиль и приватность
- Редактирование профиля и аватара, юзернейм (создание, смена, ссылка, QR), видимость и поиск по номеру.
- Safety numbers, key transparency, проверка ключей, настройки приватности, исчезающие сообщения по умолчанию.

## 7. Звонки
- 1:1 и групповые звонки, call links: в Tauri через нативный стек RingRTC, в браузере после отдельного исследования медиастека (`docs/signal/CALLS_RESEARCH.md`).

## 8. Внешний вид
- Тема в стиле Signal (светлая и тёмная), цвета чатов и обои Signal, профили уведомлений, доступность, локализация EN/RU.

## 9. Резервные копии и остальное
- Secure backups, attachment backfill, платежи MobileCoin (показ и отправка, если возможно на платформе), бейджи.

## 10. Надёжность
- Аудит безопасности, фаззинг парсеров, шифрование локальной базы код-паролем, профилирование скорости, консоль без ошибок, сквозные тесты на живом тестовом аккаунте, документация развёртывания.

## 11. Второй клиент на Telegram Web K
- После итераций 1–10: склонировать Telegram Web K в этот репозиторий и превратить его в клиент Signal по тем же требованиям: полный набор функций Signal, без кода Telegram API и Telegram-функций, тема в стиле Signal, Tauri-версия, приватность и безопасность.
- Туннель `proxy/` общий для обоих клиентов.
- Движок `src/lib/signal/` и `rust/signal-wasm` переиспользуются, а не копируются. Для этого их нужно вынести в общий пакет. Сейчас движок импортирует из кода Web A только утилиты: `util/encoding`, `util/schedulers`, `util/serverTime`, `util/browser/idb` и `util/qrCode`.
